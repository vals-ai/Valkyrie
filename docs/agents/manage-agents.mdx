---
title: Manage agents
description: Install, upload, list, download, and remove agent bundles.
---

The CLI and standalone SDK manage agents through Tracker. Bundles use the shared `agents/` layout in the bucket resolved by your existing configuration. Every agent must contain a valid [agent contract](/agents/agent-contract).

Uploads and removals use the existing deployment permissions. A hosted deployment can allow reads but deny writes. Development and self-hosted deployments can permit writes without changing the CLI or SDK. A storage permission error requires an operator to check the deployment's S3 access; retrying with another alias does not grant access.

Browse compatible community agents in the [public agent registry](https://github.com/vals-ai/public-agent-registry).

`--name` defaults to the `name` field in the agent's `contract.yaml` on both install and push. Full syntax for each command is in the [`agent install`](/reference/cli/agent#install), [`agent push`](/reference/cli/agent#push), [`agent list`](/reference/cli/agent#list), [`agent download`](/reference/cli/agent#download), and [`agent remove`](/reference/cli/agent#remove) reference.

## Install from GitHub

```bash
valkyrie agent install https://github.com/user/my-agent --name my-agent
```

The SDK clones the repository with local Git, includes submodules, bundles it, and uploads it through Tracker. GitHub `/tree/branch/subfolder` URLs install just that subfolder. Both install and push replace an existing library alias. `--name` changes the alias and archive root without rewriting the contract's name.

## Push a local agent

```bash
valkyrie agent push ./agents/sweagent --name sweagent
```

## List agents

```bash
valkyrie agent list
```

The interactive list supports `[h]` for previous, `[l]` for next, and `[q]` to quit.

## Download an agent

```bash
valkyrie agent download sweagent --output-dir ./agents
```

The SDK extracts into `./agents/sweagent` in this example. The output directory defaults to the current directory. Downloads reject an existing target unless you pass `--overwrite`; that option replaces the agent directory only after the archive passes validation. Other directories remain untouched.

Archives reject path traversal, symlinks, duplicate paths, and corrupt content. Downloads use a temporary presigned URL without forwarding Tracker credentials.

## Use the standalone SDK

[`client.agents`](/reference/sdk/agents) provides `list`, `push`, `download`, `remove`, and GitHub `install`. The SDK requires no AWS or Tracker package. Use `name=` to override the library alias and `overwrite=True` to replace a downloaded directory.

Tracker defaults to a 1 GiB upload, 5 GiB expanded content, and 100000 archive entries. Exceeded limits return HTTP 413. Operators can [configure archive limits](/contributing/tracker-service#agent-library-limits).

## Remove an agent

```bash
valkyrie agent remove sweagent
```

<Warning>
  Removing an agent deletes its S3 bundle and cannot be reversed. The CLI asks for confirmation before deletion.
</Warning>
