# Python SDK

Use Valkyrie's async Python SDK to manage runs from Python. The SDK requires Python 3.12 or newer.

## Installation

Install the standalone package from PyPI:

```bash
pip install valkyrie-sdk
```

The package does not install the Valkyrie CLI or tracker service.

## Quickstart

The SDK reads the same config as the CLI. See [Hosted vs Self-Hosted Mode](../HOSTED_MODE.md) for setup.

```python
from valkyrie.sdk import ValkyrieClient

async with ValkyrieClient.from_config() as client:
    runs = await client.runs.list()
```

Pass `base_url` to `ValkyrieClient` for a self-hosted tracker. Otherwise, the SDK uses
`TRACKER_SERVICE_URL` or the hosted tracker URL.

The SDK sends AWS credentials in `X-Harness-*` headers. Only connect to trusted trackers, and use
HTTPS outside local development.

## Run lifecycle

Start a run with an uploaded agent name or `AgentContractRequest`:

```python
run = await client.runs.start(
    agent="sweagent",
    benchmark="swebench",
    model="anthropic/claude-sonnet-4-6",
    concurrency=10,
    dataset="default",
    label="nightly-swebench",
)
```

Fetch or stream run updates:

```python
current = await client.runs.fetch(run.run_id)

async for update in client.runs.stream(run.run_id):
    print(update.details.status)
```

Use the other run methods:

```python
page = await client.runs.list()
results = await client.runs.results(run.run_id)
await client.runs.update(run.run_id, concurrency=20)
await client.runs.stop(run.run_id)
await client.runs.resume(run.run_id, concurrency=20)
await client.runs.retry(run.run_id, task_ids=["task-1"])
```

Fetch stored launch metadata or check whether canonical S3 results already exist:

```python
metadata = await client.runs.metadata(run.run_id)
exists = await client.runs.results_exist(run.run_id)
```

Analyze a finished run. Uncached analysis requires the analyzer Lambda name from the agent contract:

```python
async for event in client.runs.analyze(
    run.run_id,
    lambda_function="my-agent-analyzer",
):
    print(event.event, event.data)
```

Stream the run-output tar archive without loading it all into memory:

```python
from pathlib import Path

with Path("run-outputs.tar").open("wb") as archive:
    async for chunk in client.runs.stream_outputs(run.run_id):
        archive.write(chunk)
```

## Inspect runs and tasks

Use `client.runs` for detailed, paginated hosted-run views:

```python
from valkyrie.sdk import FetchTasksRequest, TaskStatus

details = await client.runs.fetch(run.run_id)
statuses = await client.runs.statuses([run.run_id])
tasks = await client.runs.tasks(
    run.run_id,
    FetchTasksRequest(status=[TaskStatus.ERROR], limit=25),
)
task = await client.runs.task(run.run_id, tasks.tasks[0].task_id)
artifacts = await client.runs.artifacts(run.run_id, task.task_id)
```

Artifact methods return temporary URLs generated by Tracker. The SDK does not expose internal S3 keys or clients.
Tracker's task-detail routes do not support task IDs containing `/`; the SDK rejects those IDs before sending a request.

## Discover agents and benchmark services

List uploaded agents or request a temporary download URL:

```python
agents = await client.agents.list()
download = await client.agents.download_url(agents.agents[0].name)
```

Discover and check hosted benchmark services, or fetch task IDs for a dataset:

```python
services = await client.services.list()
task_ids = await client.services.task_ids("swebench", dataset="default")
```

Local agent packaging, S3 upload/download, and artifact download-to-disk remain CLI workflows for now.

## Errors

All SDK exceptions inherit from `ValkyrieSDKError`:

```python
from valkyrie.sdk import ValkyrieAPIError, ValkyrieSDKError

try:
    run = await client.runs.fetch(run_id)
except ValkyrieAPIError as exc:
    print(exc.status_code, exc.detail)
except ValkyrieSDKError as exc:
    print(exc)
```
