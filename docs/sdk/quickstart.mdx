The `valkyrie-sdk` package is an async Python client for starting and inspecting runs from your own code. It needs Python 3.12 or newer, and it installs neither the CLI nor the tracker service.

## Install

```bash
pip install valkyrie-sdk
```

## Configure

`ValkyrieClient()` uses the same Tracker and credentials as the CLI.

```python
import asyncio

from valkyrie.sdk import ValkyrieClient


async def main() -> None:
    async with ValkyrieClient() as client:
        runs = await client.runs.list()
        print(runs)


asyncio.run(main())
```

To choose the Tracker or access key in code, see [Configure the Python SDK](/get-started/configuration#configure-the-python-sdk). The [`ValkyrieClient` reference](/reference/sdk/client) lists every constructor parameter and default.

Execution uses server-configured AWS resources and authority. See [hosted execution](/get-started/hosting#hosted-mode).

## Examples

The repository includes complete scripts for common workflows:

- [`run_lifecycle.py`](https://github.com/vals-ai/Valkyrie/blob/prod/docs/sdk/examples/run_lifecycle.py) starts, streams, and retrieves a run.
- [`manage_run.py`](https://github.com/vals-ai/Valkyrie/blob/prod/docs/sdk/examples/manage_run.py) stops, resumes, or retries a run.

From a Valkyrie checkout:

```bash
python docs/sdk/examples/run_lifecycle.py --help
python docs/sdk/examples/manage_run.py --help
```
