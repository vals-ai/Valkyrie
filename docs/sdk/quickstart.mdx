The Valkyrie SDK is an async Python client for starting and inspecting runs from your own
code. It needs Python 3.12 or later, and uses the same login and Tracker as the Valkyrie CLI.

## Install

With uv installed and a Python 3.12+ virtual environment activated:

```bash
uv pip install --exclude-newer "7 days" --exclude-newer-package certifi=false \
  "valkyrie-sdk @ git+https://github.com/vals-ai/Valkyrie@prod#subdirectory=packages/valkyrie-sdk"
```

The SDK doesn't install the CLI. Sign in once with [`valkyrie login`](/get-started/configuration#sign-in),
or set `VALKYRIE_API_KEY` to an [access key](/get-started/configuration#create-an-access-key-for-ci).

## List your runs

```python
import asyncio

from valkyrie.sdk import ValkyrieClient


async def main() -> None:
    async with ValkyrieClient() as client:
        page = await client.runs.list()
        for run in page.benchmarks:
            print(run.id, run.name, run.status, run.final_score)


asyncio.run(main())
```

`ValkyrieClient()` sends requests to the Tracker you last signed in to. To pick the Tracker
or access key in code, see [Configure the Python SDK](/get-started/configuration#configure-the-python-sdk).

## Handle errors

Every SDK exception inherits from `ValkyrieSDKError`. Catch `ValkyrieAPIError` when you
need the HTTP status or the Tracker's error detail:

```python
from valkyrie.sdk import ValkyrieAPIError, ValkyrieSDKError

try:
    run = await client.runs.fetch(run_id)
except ValkyrieAPIError as exc:
    print(exc.status_code, exc.detail)
except ValkyrieSDKError as exc:
    print(exc)
```

The [errors reference](/reference/sdk/errors) lists every exception.

## Run the example scripts

The repository has two complete scripts. Run them from a Valkyrie checkout:

```bash
# Start a run, stream its progress and download its results
python docs/sdk/examples/run_lifecycle.py --help

# Stop, resume or retry a run
python docs/sdk/examples/manage_run.py --help
```
