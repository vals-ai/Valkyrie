## `valkyrie secret set` {#set}

Store a secret, replacing its value if it already exists.

Reads one line from a hidden prompt, or the whole value from stdin when piped; pipe multi-line values such as JSON. The value is never taken from the command line. Prints the reference to use as the secret name.

```bash Syntax
valkyrie secret set \
  <NAME>
```

```bash Example
# Example only, review before running
valkyrie secret set openai-key
valkyrie secret set daytona < daytona.json
```
