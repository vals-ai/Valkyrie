## `valkyrie project create` {#create}

Create a project that runs can be started in with `valkyrie run start --project HANDLE`.

HANDLE is the project's permanent handle: lowercase letters, digits and hyphens (e.g., my-project).

```bash Syntax
valkyrie project create \
  <HANDLE> \
  --name <TEXT> \
  --spend-type <CHOICE> \
  --subcategory <CHOICE> \
  [--customer <TEXT>] \
  [--tag <TEXT>...]
```

```bash Example
# Example only, review before running
valkyrie project create \
  my-project \
  --name "My Project" \
  --spend-type development \
  --subcategory new_benchmark_generation
```
