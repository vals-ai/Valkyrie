## `valkyrie benchmark service set` {#service-set}

Use a service URL for your runs of a benchmark.

Replaces the URL and credential saved before. The Tracker must be able to reach the URL.

```bash Syntax
valkyrie benchmark service set \
  <BENCHMARK> \
  <URL> \
  [--auth-secret <SECRET>] \
  [--auth-header <HEADER>]
```

```bash Example
# Example only, review before running
valkyrie benchmark service set \
  swebench \
  https://my-tunnel.ngrok.io \
  --auth-secret swebench-key
```
