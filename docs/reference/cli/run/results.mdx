Retrieve run results by its run id.

<Panel>
<CodeGroup>

```bash Syntax
valkyrie run results \
  <RUN_ID> \
  [--path <PATH>] \
  [--s3] \
  [--task-ids <TEXT>] \
  [--task-ids-file <TEXT>]
```

```bash Example
valkyrie run results \
  123e4567-e89b-12d3-a456-426614174000 \
  --path ./results-123e4567-e89b-12d3-a456-426614174000.json
```
