---
title: AWS permissions
description: Scope the server and local AWS authority used by Valkyrie.
---

Tracker and executor processes use their server IAM roles for artifact storage, logs, sandbox-provider secrets, and optional post-run integrations. [Hosted execution](/get-started/hosting#hosted-mode) uses deployment-configured resources.

| Service | Permissions | Used for |
| --- | --- | --- |
| S3 | `s3:PutObject`, `s3:GetObject`, `s3:DeleteObject`, `s3:ListBucket` | Benchmark results, agent artifacts, and run outputs |
| CloudWatch Logs | `logs:CreateLogGroup`, `logs:CreateLogStream`, `logs:PutLogEvents` | Task execution logs |
| Secrets Manager | `secretsmanager:GetSecretValue` | Configured sandbox-provider and benchmark-service secrets |
| Lambda (optional) | `lambda:InvokeFunction` | Configured post-run functions |

Scope each server role to its configured buckets, log groups, functions, and secret names. The default sandbox-provider secret must match an allowed Tracker secret-name prefix.
